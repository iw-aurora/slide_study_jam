# Week 01 — Version Control, Git và GitHub

## Chủ đề

Tổng quan về quản lý phiên bản, Git, GitHub và các nền tảng hỗ trợ cộng tác.

## Nội dung

1. **Version Control & Git**
   - Khái niệm quản lý phiên bản.
   - Local VCS, CVCS và DVCS.
   - Git và các đặc điểm chính.
   - Working Tree, Staging Area và Git Directory.
   - Cài đặt và cấu hình Git trên Windows.

2. **GitHub & các nền tảng cộng tác**
   - GitHub và sự khác nhau giữa Git với GitHub.
   - Repository, Branch, Pull Request, Issues, GitHub Actions và Projects.
   - GitLab và Bitbucket.
   - Quy trình cộng tác nhóm và demo GitHub cơ bản.
